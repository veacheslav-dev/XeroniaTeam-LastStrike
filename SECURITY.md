# Политика безопасности

## Сообщение о проблемах
Если вы обнаружили проблему, связанную с безопасностью (например, вредоносную ссылку, подозрительный файл или нарушение авторских прав), пожалуйста, сообщите нам **приватно**.
**Не создавайте публичный Issue по вопросам безопасности.**

## Как связаться
Напишите на почту: [help@xeronia.ru] (или создайте приватный Security Advisory через вкладку Security в репозитории).

## Что считается проблемой безопасности
- Вредоносный код в аудиофайлах
- Ссылки на фишинговые или опасные сайты
- Нарушение лицензии CC BY 4.0 (использование музыки без указания авторства)
- Любые другие подозрительные действия

## Сроки ответа
Мы постараемся ответить в течение 3-5 рабочих дней.
