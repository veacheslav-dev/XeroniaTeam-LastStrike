# XeroniaTeam-LastStrike

Репозиторий игры LastStrike для хранения музыкальных композиций.

## О репозитории
Здесь собраны все музыкальные композиции, созданные командой **XeroniaTeam** для игры **LastStrike**. Треки предназначены для использования в игре, в том числе при создании кастомных уровней сообществом.

## Как использовать музыку
Вы можете:
- **Скачивать** любые композиции из этого репозитория.
- **Использовать** их во время игры в LastStrike.
- **Адаптировать** треки под свои нужды.

## Важно
- **Авторство `XeroniaTeam` остаётся всегда.** Указывайте его везде, где используется музыка.
- Музыку **можно** использовать в коммерческих проектах.
- Музыку **нельзя** выдавать за свою собственную.
